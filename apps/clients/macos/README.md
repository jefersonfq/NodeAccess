# NodeAccess para macOS

Pasta reservada ao aplicativo macOS. Sem código executável ou ferramenta de build nesta etapa.

## Experiência a validar

- Configuração da instalação e autenticação conforme o escopo definido.
- Navegação entre hosts e sessões com teclado.
- Terminal: atalhos, seleção, colagem, foco, redimensionamento e múltiplas sessões.
- Suspensão do computador, retorno e mudança de rede.
- Integração com arquivos locais e armazenamento de credenciais, quando necessários.

## Critério para começar a implementação

Escolher tecnologia após comprovar o terminal em macOS. Planejar compilação, assinatura, distribuição e atualização separadamente; nenhuma etapa de publicação está habilitada.
