# Licenciamento NodeAccess — base interna para documento separado

Status: preparação editorial; não é uma lista de preços nem material final para envio ao cliente.

Diretriz comercial confirmada por Jeferson em 24/09/2026: o licenciamento é por **quantidade de elementos observados**, não por tenant. Tenant representa uma organização/um contexto operacional; sua existência não define a unidade comercial de licenciamento.

A definição contratual de elemento observado, faixas, valores, periodicidade e condições comerciais serão estabelecidas no documento específico. Não foram informados preços para esta revisão.

O datasheet de produto não inclui a seção de licenciamento. Quotas técnicas ou telas de administração por tenant não devem ser descritas como a unidade de cobrança.
