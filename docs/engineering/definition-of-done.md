# Definition of Done

Uma mudança está pronta somente quando:

- [ ] Change ID, plano e branch correspondem entre si.
- [ ] Situação anterior, problema, escopo e fora de escopo estão documentados.
- [ ] Critérios de aceitação testáveis foram atendidos.
- [ ] Diff revisado contra o plano, sem expansão silenciosa.
- [ ] Testes foram criados ou atualizados e o baseline foi registrado.
- [ ] Lint, typecheck, build e suites aplicáveis passaram.
- [ ] Harness e evidências correspondem ao último SHA.
- [ ] Segurança, performance, migrações e rollback foram avaliados quando aplicáveis.
- [ ] PR documenta antes, implementado, depois e riscos residuais.
- [ ] Homologação técnica independente e homologação funcional humana foram registradas.
