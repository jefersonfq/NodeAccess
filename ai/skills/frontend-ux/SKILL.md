name: frontend-ux
description: Use esta skill para desenhar ou revisar interfaces com foco em usabilidade, acessibilidade, visualização de dados e consistência visual.


Objetivo
Avaliar e melhorar UX e UI sem perder simplicidade de implementação.
Priorizar clareza, baixa carga cognitiva, boa hierarquia visual e tomada de decisão rápida.
Sempre analisar
UX
•	clareza da navegação
•	fluxo do usuário
•	facilidade de descoberta das funcionalidades
•	feedback de ações
•	prevenção de erros
•	acessibilidade
UI
•	hierarquia visual
•	alinhamento
•	espaçamento
•	consistência dos componentes
•	contraste
•	responsividade
Arquitetura da Informação
•	excesso de informação na tela
•	agrupamento lógico de conteúdo
•	priorização das informações
•	facilidade de escaneamento visual
•	necessidade real de cada elemento exibido
Dados e Dashboards
•	os gráficos realmente agregam valor?
•	existe uma forma mais simples de apresentar a informação?
•	há excesso de métricas simultâneas?
•	a informação crítica está evidente?
Preferir:
•	KPIs
•	tabelas resumidas
•	gráficos de linha
•	gráficos de barras
•	tendências
Evitar:
•	muitos gráficos na mesma tela
•	excesso de cards
•	excesso de cores
•	dashboards poluídos
•	gráficos sem contexto
Princípios
•	Menos é mais
•	Clareza acima de estética
•	Destacar exceções antes dos detalhes
•	Mostrar resumo antes do aprofundamento
•	Dados importantes devem ser encontrados em menos de 5 segundos
Checklist
Clareza
•	Existe CTA principal claro?
•	O usuário entende o próximo passo?
•	O objetivo da tela é evidente?
Simplicidade
•	Existe informação redundante?
•	Algum componente pode ser removido?
•	Existe poluição visual?
Estados
•	loading
•	erro
•	vazio
•	sucesso
•	sem permissão
Formulários
•	minimizam erros?
•	possuem validações claras?
•	possuem exemplos quando necessário?
Responsividade
•	funciona bem em desktop?
•	funciona bem em tablet?
•	funciona bem em mobile?
Acessibilidade
•	contraste adequado?
•	foco visível?
•	navegação por teclado?
•	mensagens compreensíveis?
Regra Final
Sempre questionar:
“Essa informação precisa estar visível agora?”
Se não for essencial para a tomada de decisão imediata, considerar esconder atrás de filtros, abas, expansão ou drill-down.
