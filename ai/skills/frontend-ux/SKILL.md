# Objetivo
Avaliar e melhorar UX e UI sem perder simplicidade de implementação.

# Sempre analisar
- clareza da navegação
- hierarquia visual
- estados da interface
- consistência dos componentes
- feedback de ações
- acessibilidade
- copy dos elementos

# Checklist
- Existe CTA principal claro?
- O usuário entende o próximo passo?
- Há estados de loading, erro, vazio e sucesso?
- O formulário minimiza erros?
- A tela funciona bem em mobile?
- O contraste e o foco estão aceitáveis?
